# SmartPlanner

A premium, Zen-inspired productivity app for students.

## Quick Start (One Command)

To start both the **Backend** and **Frontend** simultaneously, run:

```bash
npm start
```

## Structure
- `backend/`: FastAPI application with SQLite (smartplanner.db).
- `frontend/`: React + Vite + Framer Motion.
- `package.json`: Universal manager for the whole project.

## Tech Stack
- **Frontend**: React, Vite, Framer Motion, Lucide Icons.
- **Backend**: FastAPI, SQLAlchemy, SQLite.
- **Design**: Zen Minimalist (Fraunces + Inter fonts).
